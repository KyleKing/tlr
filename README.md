# tlr

Triage, capacity, and goals for a tech lead, from Linear and Pylon, in a terminal, but
you probably want to use one of these instead:

| Service                                                            | Notes                                                                                                |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| [bugwarrior](https://github.com/ralphbean/bugwarrior)              | "a command line utility for updating your local taskwarrior database from your forge issue trackers" |
| [gh](https://github.com/cli/cli)                                   | "gh is GitHub on the command line"                                                                   |
| [gh-dash](https://github.com/dlvhdr/gh-dash)                       | "A rich terminal UI for GitHub that doesn't break your flow"                                         |
| [git-bug](https://github.com/git-bug/git-bug)                      | "Distributed, offline-first bug tracker embedded in git"                                             |
| [GLab](https://gitlab.com/gitlab-org/cli)                          | "A GitLab CLI tool bringing GitLab to your command line"                                             |
| [hut](https://git.sr.ht/~xenrox/hut)                               | "A CLI tool for sr.ht"                                                                               |
| [jira-cli](https://github.com/ankitpokhrel/jira-cli)               | "Feature-rich Interactive Jira Command Line"                                                         |
| [linear-cli](https://github.com/nesszer/linear-cli)                | "A fast, comprehensive command-line interface for Linear built in Rust"                              |
| [linear-cli](https://github.com/schpet/linear-cli)                 | "linear without leaving the command line: list, start, and create PRs for linear issues"             |
| [pylon-cli](https://github.com/Escape-Technologies/pylon-cli)      | "CLI for Pylon — for humans and AI agents"                                                           |
| [Shortcut](https://www.shortcut.com)                               | "Project management for software teams and their agents" (Closed source)                             |
| [Taskell](https://github.com/smallhadroncollider/taskell)          | "Command-line Kanban board/task manager with support for Trello boards and GitHub projects"          |
| [Taskwarrior](https://github.com/GothenburgBitFactory/taskwarrior) | "manages your TODO list from the command line"                                                       |
| [taskwarrior-tui](https://github.com/kdheepak/taskwarrior-tui)     | "A Terminal User Interface (TUI) for Taskwarrior"                                                    |
| [tea](https://gitea.com/gitea/tea)                                 | "The official CLI for Gitea"                                                                         |
| _[Awesome TUIs](https://github.com/rothgar/awesome-tuis)_          | "List of projects that provide terminal user interfaces"                                             |
