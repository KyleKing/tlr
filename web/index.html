Planning board

Spike on real Contractual Product Uptime data. Placement: an issue in an active cycle shows in that cycle column, else its milestone, else Backlog. Capacity heat is a forecast against the adjustable points/person/week knob (milestone columns scale it by weeks in the window), not real velocity. Flags: ⚠ slop scans the description for AI tells (dashes, semicolons, checklists, length, stock phrases); ⛔ ordering risk means a blocker finishes after the issue it blocks; ◑ missing marks absent estimate, assignee, or milestone, but only for issues already committed to a cycle. Hover a ticket for details and its blocking relations, and to mark a false-positive slop flag as reviewed (it stays cleared until the ticket text changes). Double-click a status chip to show only that status; "Rows: people" flips the grid so buckets run down the side when heavy filtering leaves few columns.
